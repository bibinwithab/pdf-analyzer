
# Pdf analyzer RAG application

A full stack RAG application that helps students learn and extract info from long pdfs via text extraction, summarization, explaination and also curates MCQs and Flashcards using FAISS vector database.

## Table of Contents
- [Installation](#installation)
- [Usage](#usage)
- [Questions](#questions)

## Usage
##### Frontend
```bash
cd frontend
npm install
npm run dev
```
##### Backend
```bash
cd backend
python setup.py
<activate the virtual env>
pip install requirements.txt
uvicorn main:app --reload
```
